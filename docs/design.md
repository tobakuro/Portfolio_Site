# tobakuroのポートフォリオサイト

## MVP

- 自己紹介
  - 氏名, 学校名・学部・学科, 学年
  - 趣味
  - SNS
  - 技術領域, 使用技術
- これまでの成果物(カードの形で表示)
- 最近のニュース(イベント参加等)
- 最近の開発状況 (githubAPIを用いてなにか表示)

## このプロダクトで開発上重視すること

- 軽量, 高速かつ高度なデザイン(UI・UXを重視)
- データ更新が容易にできる設計
  - 成果物カード, 最近の活動などの長期的に更新する要素を管理者が簡単に更新できる仕組みを作る

## 技術選定

### フロントエンド: Astro × React
- 静的生成ベースで高速・高スコアなUIを実現
- 必要な箇所だけReactコンポーネント（Island Architecture）を使う
- TypeScript使用

### コンテンツ管理: Markdownファイル
- `content/works/`, `content/news/` 等にMarkdownで管理
- Astroのコンテンツコレクション機能で型安全に読み込む
- 更新はMarkdownを編集してgit pushするだけ

### バックエンド: Go (REST API)
- 動的データの取得に限定して使用
  - GitHub APIプロキシ（最近のコミット・リポジトリ情報）
  - 問い合わせフォーム受信（将来的に）
- Markdownで管理できるデータはGoを経由させない

### データベース: なし
- 静的コンテンツはMarkdownで管理するためDBは不要

### クラウドサービス
| 役割 | サービス |
|------|----------|
| フロントホスティング | Cloudflare Pages |
| Go APIサーバー | Fly.io |

- **Cloudflare Pages**: 無料枠が広い、CDN込み、GitHub連携でCI/CD自動化
- **Fly.io**: 小コンテナを無料枠で運用可能、Dockerベースでインフラ学習にもなる
